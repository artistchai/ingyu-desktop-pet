# 인규 데스크탑 펫👽

책상 위 작은 친구, 인규가 놀러 왔어요! 
뽀모도로 타이머로 함께 일하고 함께 쉬는 3D 데스크탑 펫 인규입니다🛸



## 다운로드

[Releases 페이지](https://github.com/artistchai/ingyu-desktop-pet/releases/latest)에서 자신의 컴퓨터에 맞는 파일을 받아주세요❗️



### 🍎 Mac 사용자

내 Mac이 어떤 칩을 쓰는지 궁금하다면? 화면 왼쪽 위 Apple 메뉴 → 이 Mac에 관하여에서 슬쩍 확인해보세요!👀

| 칩 종류 | 받을 파일 |
|---|---|
| Apple M1 / M2 / M3 / M4 (2020년 말 이후 출시된 대부분의 Mac) | `인규-Mac-arm64용.dmg` |
| Intel (2020년 이전 구형 Mac) | `인규-Mac-x64용.dmg` |

**"확인되지 않은 개발자⚠️" 경고가 뜬다면 당황하지 마세요!:**
1. 다운로드한 `.dmg` 파일을 열어 앱을 Applications 폴더로 옮겨주세요.
2. Applications 폴더에서 인규 아이콘을 마우스 우클릭(또는 Control+클릭) → 열기를 눌러주세요.
3. 경고창이 다시 뜨면 한 번 더 **"열기"**를 눌러주세요 — 이제 인규가 여러분을 만나러 나올 거예요!👽



### 🪟 Windows 사용자

`인규-설치파일-Windows.exe`를 다운로드해서 실행해주세요.

Windows Defender SmartScreen⚠️ 경고가 뜨면 **추가 정보 → 실행**을 눌러 인규를 맞이해주세요.



## 주요 기능

🖥️ 책상 위에서 열심히 작업하는 3D 캐릭터 인규
⏱️ 뽀모도로 타이머 (작업/휴식 시간 마음대로 조절 가능)
⌨️ 작업 시간엔 타이핑도 하고 마우스도 조물조물
😴 휴식 시간엔 책상 위에서 폐급 낮잠
📄 열심히 일할수록 옆에 쌓여가는 서류 뭉텅이
