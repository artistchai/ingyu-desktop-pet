# 인규 데스크탑 펫

뽀모도로 타이머와 함께하는 3D 데스크탑 캐릭터, 인규입니다.

## 다운로드

[Releases 페이지](https://github.com/artistchai/ingyu-desktop-pet/releases/latest)에서 자신의 컴퓨터에 맞는 파일을 받아주세요.

### Mac 사용자

내 Mac의 칩 종류가 궁금하다면 화면 왼쪽 위 **Apple 메뉴 → 이 Mac에 관하여**에서 확인할 수 있어요.

| 칩 종류 | 받을 파일 |
|---|---|
| Apple M1 / M2 / M3 / M4 (2020년 말 이후 출시된 대부분의 Mac) | `인규-Mac-arm64용.dmg` |
| Intel (2020년 이전 구형 Mac) | `인규-Mac-x64용.dmg` |

**설치 시 "확인되지 않은 개발자" 경고가 뜬다면:**
1. 다운로드한 `.dmg` 파일을 열어 앱을 Applications 폴더로 옮겨주세요.
2. Applications 폴더에서 인규 아이콘을 **마우스 우클릭(또는 Control+클릭) → 열기**를 선택해주세요.
3. 경고창이 뜨면 다시 한 번 "열기"를 눌러주시면 정상적으로 실행돼요.

### Windows 사용자

`인규-설치파일-Windows.exe`를 다운로드해서 실행해주세요.

Windows Defender SmartScreen 경고가 뜨면 **추가 정보 → 실행**을 눌러주시면 설치가 진행돼요.

## 주요 기능

- 책상 위에서 작업하는 3D 캐릭터 인규
- 뽀모도로 타이머 (작업/휴식 시간 커스터마이즈 가능)
- 작업 중에는 타이핑, 마우스 조작 등 다양한 자세
- 휴식 시간에는 책상 위에서 낮잠
- 작업량에 따라 쌓이는 서류 뭉텅이
